# Canyon Comfort — HVAC website concept

This is a fictional residential HVAC website sample by Daxton Zimmerman. It is not a real business, client project, or a working lead collection system.

Open `dist/index.html` to view it locally. All visual assets used by the page are in `dist/assets/`. The inquiry form demonstrates the interaction but does not send or save information.

Before using this for a real client, replace the name, copy, service claims, location, imagery, and contact flow with owner-approved details. Connect and test the inquiry route, then confirm scope and hosting terms separately.
